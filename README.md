# LMU Open Science Center Slides

## Installing

### As A New Quarto Project


```bash
quarto use template lmu-osc/osc-slides
```

This will install the extension and create an example qmd file that you can use as a starting place for your article.

### To An Existing Project

```bash
quarto add lmu-osc/osc-slides
```

This will add the extension to the specific project you are working on. (Note: this is not a global installation of the extension! You will need to install in each project where you wish to use the extension.)
